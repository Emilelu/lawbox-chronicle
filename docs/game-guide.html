核心系统

推箱（立体高度层）

  • 把所有箱子推上旗位基座（■）即过关；步数决定星级（每关 3★ / 2★ 两档步数线）。
  • 立体关卡存在高度层：爬升有上限（CLIMB_LIMIT），把箱子推下高台会坠落砸压下方的守卫或目标——地形本身是武器。
  • 尖刺格：战斗布阵期可把敌人推进尖刺按比例扣血。
  • 阴阳位面：按 F 切换表里世界，阴面有另一套地形与浮空石板（需「位面通行」法则卡）。
  • 撤销（Z）可回滚任意步，含被消除的箱子；死锁检测会在无解局面时提示。

回合战斗（布阵推挤）

  • 踩到敌人触发遭遇战：先布阵——怪物方块化（重量∝HP）摆上 3D 战场网格，可用方向键/屏幕键推挤。
  • 推下深渊、推进尖刺按比例扣血甚至秒杀小怪；BOSS 免疫推挤（附护盾与弱点机制），必须走公式战。
  • 伤害 = 攻 − 防（下限 0），武器提供攻击加成，部分武器有特殊效果（击退 / 多次使用）。

抽卡与法则卡

  • 星石来源：关卡星级结算 / 挑战层 / 剧情。定价：单抽 100◈、十连 900◈。
  • 概率：4★ 6% / 3★ 26% / 2★ 68%（逐卡独立 roll，概率公示面板可查）。
  • 三层保底：①十连末位必 3★+；②累计 50 抽必出 4★；③累计 40 抽未获未持有法则卡 → 定向补齐。
  • 重复法则卡自动转 20 碎片；60 碎片可在卡组·商店页签直购任一未持有法则卡——零软锁。
  • 法则卡是核心融合玩法：激活后实时改写推箱物理与战斗参数（羽箱减重、推程+1、镜像拉箱、斜向推挤、相位穿行、箱落引爆、位面之眼……）。
  • 怀旧对照池：完整复刻原邦邦抽卡模拟器的概率缺陷，作为「概率展品」与正式池并列，档案页可一键跑对照十连并查看双池实测出货曲线。

收集与存档

  • 档案面板：卡牌图鉴（首获/次数）、成就、双池出货实测曲线、逐抽记录。
  • 存档为 localStorage 三分片（进度/偏好、档案、抽卡统计），刷新与关浏览器都不丢；标题页可重置。
